# agent-manager

The middle layer between `agent-manager-ui` (browser) and `agent-daemon`
(holds the agent processes on `127.0.0.1:4267`). It owns projects, agents
and users, understands the agent CLIs' protocols, and exposes an
authenticated REST + websocket API. `docs/design.md` is the source of
truth; read it before changing behaviour and update it when a decision
changes.

## Rules that follow from the design

- All agent-protocol knowledge lives in `src/adapters/`. Nothing outside an
  adapter parses a vendor line, and the UI never sees raw lines.
- The manager must be rebuildable from the daemon: never store anything
  about a session's content that cannot be regenerated by replaying its
  daemon log. Restarting the manager must be a non-event for agents.
- Never send `session.remove` to the daemon.
- Every route and the websocket require the session cookie except login.
- An agent is not a process. It spans daemon sessions; the next turn after
  an exit resumes through the vendor's own mechanism.
- The fake adapter and profile must keep working; UI e2e tests depend on
  them and they are how to develop without spending tokens.

## Stack and commands

NestJS 12 on Node 24, ESM (`.js` import suffixes), better-sqlite3, argon2,
vitest, oxlint + prettier.

```
npm run start:dev       # watch mode; expects a running agent-daemon
npm test                # unit tests (adapters against recorded logs, etc.)
npm run test:e2e        # starts a real daemon with the fake profile on an ephemeral port
npm run install:service # installs/restarts the user service; agents are unaffected
```

## Working here

- The sibling repositories are `../agent-daemon` and `../agent-manager-ui`.
  The daemon's protocol is in `../agent-daemon/docs/client-guide.md`.
- Restarting the manager is fine at any time. Restarting the daemon is not;
  see `../agent-daemon/CLAUDE.md`.
- Review loop as in `../agent-daemon/docs/reviewing.md`: Codex deep with the
  custom prompt, `claude -p` for cheap passes, reviewers report, we fix.
- Prettier reformats aggressively; do not rely on exact-text matches of
  source you have not just read.
